Advanced / backup RAM & format details

Audio has not been enabled.

CHD: self-contained v5 CD-ROM, cdlz/cdzl/cdfl or uncompressed, up to 1,058,400,000 bytes. ISO: cooked 2048-byte sectors, 18–450,000 sectors (921,600,000 bytes). CUE: all referenced BINARY tracks, up to 1,058,400,000 track bytes plus a 1 MiB CUE. A lone raw BIN needs its CUE. SRW1 companions are optional diagnostics only when explicitly referenced by a CUE. Large images need sufficient browser memory.

HLE loads the first data track’s Saturn IP / ISO9660 executable. BIOS mode mounts the medium for firmware to read through hardware. No extraction or private sidecar is needed for ordinary discs. A BIOS must be an authorized raw 512 KiB file; size does not verify authenticity or region. The advanced fixture clears both image selections; Restart retains selected media and backup RAM.

Controls, privacy & compatibility

Focus the display for keyboard input. Arrows control directions, Z is A and Enter is Saturn Start. Second pad: I/K/J/L directions, U/O/P for A/B/C, Right Shift for Start. Losing focus releases held input; hiding the tab pauses. Returning from Debug or closing advanced settings never resumes automatically.

Enable audio with a click; status reports blocked, muted, paused and underflow states. Fullscreen uses your browser’s API. Restart cold-boots the selected mode; Debug offers CPU Step, bounded Run, Reset and frame advance.

This is an independent emulator under development. Loading media does not guarantee that a game or retail BIOS will run. No commercial screenshots or simulated game output are shown.

Disc, BIOS and backup bytes stay in memory in this tab. No uploads, browser persistence, analytics or CDN. Export backup RAM under Advanced before closing or reloading. This is not a save state.
