saturn-rust Playable homebrew

A small original Saturn game running as guest SH-2 code with Rust VDP2 graphics and SMPC input. Silent; one supported game, no commercial-game compatibility.

Star Collector

Move the cyan square with arrow keys to touch five yellow stars. Gold blocks show your score; a green banner means you won. Enter / Start restarts inside the guest program. Click the screen to focus keyboard input.

Boot and execution

Choose an authorized image using the documented single-area IP/ISO9660 HLE boot contract. Other hardware, BIN/CUE, compressed discs and runtime BIOS/CD services are unsupported. Files stay in this tab; no upload or storage.

Use a legally obtained BIOS. Bytes stay in this tab's memory; they are never uploaded or saved by this app.

Changing mode or file performs a cold reset. User-provided BIOS mode reads real reset vectors; native Sega BIOS boot/game support is incomplete and never redirects to HLE.
