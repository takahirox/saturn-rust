Load ISO / BIOS & boot settings
Boot image

Working HLE homebrew uses a narrow single-area Saturn IP / ISO9660 cooked ISO contract. Other hardware, BIN/CUE, compressed discs and runtime BIOS/CD services are unsupported.

Use a legally obtained BIOS. Correct size validates layout, not authenticity or region. Its real reset vectors are used; native Sega BIOS boot/game support is incomplete and often stops on unimplemented device or bus behavior. BIOS mode never redirects to HLE.

Changing mode or file cold-resets the machine and clears the previous selection. Opening or closing settings does not reset; opening pauses playback. Use Resume to continue.

Local files stay in this tab's memory. No uploads, browser storage or analytics. No Sega BIOS is bundled.

Bootstrap reference

In boot settings, choose HLE bootstrap prototype, then Reset and Run 6.

R0=4 · R1=7 · PC=0x0600000E

Later runs stay in a BRA/NOP loop. Run is bounded to 10000 CPU steps; exception entry and sleeping steps may retire no instructions. This original fixture is not Saturn BIOS service emulation.

About this prototype & original game

Move the cyan square to touch five yellow stars. Gold blocks show your score; a green banner means success. Graphics and game rules execute as guest SH-2 code. This is a silent, limited hardware prototype; general homebrew and commercial-game compatibility are not supported. Keyboard required; touchscreen controls are not included.

The sample and its original graphics are MIT licensed. License · Download sample ISO · Buildable guest source

Switching Play / Debug pauses playback and releases held buttons. Returning to Play does not resume automatically. Moving focus away from the display also releases input.
